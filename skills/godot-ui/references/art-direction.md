# 美术方向：建立能被复用的视觉目标

只在新视觉方向、整幅场景、新素材家族或明确重设计时读取。小范围修复沿用既有样板，不重新出图。这里是一套选择方法，不规定所有游戏采用同一配色、二维绘景或人物比例。

## 先诊断画面为何不成立
实际看项目已有图和玩家路径。分别判断：主体不清、比例/透视不一、材质混杂、文字抢戏、内容不足、还是操作组织错误。给一个管理面板加宣纸、金边和头像，不会自动变成身处场所；反之，抽象策略图也不必伪装成房间。

选择一至三张有来源的参考，记录真正看过的图或视频片段、可观察属性、明确不借用的内容。保留来源的使用边界：参考图不是可直接打包的素材。画面风格借鉴不等于历史准确；服饰、家具、标语年代不确定的项目要标注，不能用“国风”掩盖混搭。

## 把形容词转换为制作约束
| 轴 | 写出可检查的选择 | 常见失败 |
|---|---|---|
| 镜头 | 视角、地平线、玩家与主要对象的距离 | 背景俯视、人物平视 |
| 主次 | 当前人物/行动/环境的阅读顺序 | 所有框和图标一样亮 |
| 明暗 | 主光方向、人物与背景的分离方式 | 各素材各有一盏逆光 |
| 色彩 | 环境、正文、行动、危险各自职责 | 满屏用强调色，靠金边“高级” |
| 材质与边缘 | 木/布/金属的区别，近远细节取舍 | 每件物品都同样塑料高光 |
| 人物 | 身高、头身比、服装剪影、身份特征 | 同一角色换个表情就换脸 |
| 字体与图标 | 正文与标题分工，描边/填充的一致性 | 书法正文难读，混用三套图标 |
| 动态 | 反馈时机、过渡幅度、可取消方式 | 每次操作播放不能打断的长动画 |

无需填满文档才能改代码。新场景把以上实际相关选择写入现有美术说明；同一项目只维护一处视觉约定，不复制进每个技能。

## 先做代表性画面，不先批量生产
把真实尺度的人物、环境、一个高频交互和最少必要 HUD 放在一起。优先看原生显示尺寸和缩略图，再放大检查边缘；只在放大时漂亮的细节不能补救整体构图。准备普通状态与相关拥挤/长文状态即可，不能把一次样板扩成无意义的全界面矩阵。

目标可为有明确标记的合成稿或概念图。记录作者建议、用户批准和待修改，不把“继续”自动解释为认可每个历史细节。用户委托美术选择时可推进可逆候选，但仍不伪造批准状态。

## 迭代方法
发现主体不突出，先改明暗、面积或位置；材质/风格漂移，回到同一参考种子做受约束的修改；动作不可读，先改剪影和时序。一次优先解决最影响目标的差距，不把“再精致一点”作为唯一修改说明。保留可对照的前后图与改动意图，不保留大量无意义重复截图。

## 完成边界
目标图回答视觉方向；分层文件回答可生产性；引擎画面回答实际呈现；操作轨迹回答交互。四者可以分阶段交付，不能相互冒充。技术回归继续保留，但灰盒截图不承担美术通过结论。
