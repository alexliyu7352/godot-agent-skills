# 《汉末行记》官署：视觉目标 01

状态：**视觉方向候选的制作规格**，不是已批准美术、分层资产或 Godot 实机截图。本文件由用户批准的纠偏方向具体化；实际图像仍需单独判断。所有人物姓名与谈话为样例，不写回用户游戏。

## 一句话目标
玩家跨过郡府办事厅门槛，先看见正在处理文书的人，再与其中一人交谈；界面只辅助这场会面，不能替代房间和人物。目标是成熟、精致的二维历史生活场景，不是以三国词汇包装的管理网页。

## 本轮制作范围
先做一张把环境、人物与小段对话放在一起的主画面候选。它用来检验方向，不先扩成 15 张同模板图片。场景分层、原生文字和实际交互的 Godot 接入属于下一阶段，不能由概念图声称已经完成。

保留上轮工程夹具以发现故障，但其灰盒外观不作为美术参考、不进入这个场景。没有建立第八个技能、没有新建游戏世界架构，也不触碰用户游戏仓库。

## 镜头与构图
16:9 固定镜头，设计画布参考 1600×900。站在厅堂入口稍偏左的位置向里看，轻微俯角且地平线约在上半部；不是鸟瞰小屋，也不是完全平面的舞台。左右木柱和前景案边形成框景，中部可见完整低案和席垫，右后方有层次清楚的文书架。

视觉焦点是右中部案后的主簿，其手中的简牍与抬头视线把玩家引入谈话。左后方年轻书佐正在整理成捆文书；靠外廊的门吏为入口提供尺度和秩序。人物至少在姿态、衣色和所做的事上可区分，不能只靠姓名标签。

房间背后/左侧通向亮庭院，外部绿树与瓦檐提供冷色空气感。前景有少量暗部遮挡，地面受暖斜光照射；不把每个角落填满亮点。出口是可辨认的空间，不是孤立“返回”卡片。

## 美术方向（项目候选值，不是通用 Skill 规则）
| 项目 | 选择 |
|---|---|
| 绘画语言 | 精细历史插画的半写实人物与绘景；体积明确，材质有区别；近处较清楚、远处边缘柔化 |
| 明暗 | 柔和自然光从左侧庭院进入；脸、手和正在处理的文书有阅读重点；不靠全屏黑遮罩制造对比 |
| 基础色 | 暗木与墨青为结构，暖灰/浅麻为受光面，少量赭红漆器，青灰庭院；不满屏金边 |
| 参考色值 | 结构 #25322F、暗木 #4C3C30、麻帛 #DED2B6、灰砖 #8E958A、漆红 #8C3E31、提示 #C0A16B；实际作画可校正 |
| 人物 | 真实成人比例、含蓄表情与自然手部；衣物哑光，有布料重量；不是Q版、像素人或泛仙侠铠甲 |
| 材料 | 木梁、灰砖、编织席、低案、竹木简牍、布帘；书写与收纳有使用痕迹，但不做满屏噪声 |
| UI | 克制的墨色与暖白文字、少量精细线条；短暂对白层保留环境；无需每个信息都包一张卡 |
| 节奏 | 轻微抬头、衣物呼吸、光中尘埃属于后续可选表现；不靠特效或长转场掩盖空场景 |

避免日式障子/榻榻米和刀架、明清官帽/高背官椅、红灯笼海、宫殿金龙、现代办公桌。这是有历史参照的艺术候选，不是对某个真实汉末官署的考古复原；具体制度与服饰细节仍可修订。

## 同一空间中的三种状态
| 状态 | 世界层 | 临时 UI | 验收重点 |
|---|---|---|---|
| 进入 | 主簿、书佐、门吏和文书在场；庭院出口可辨 | 上角地点/日期，悬停对象才显示短提示 | 去掉地点标题仍像有人办事的厅堂 |
| 与主簿交谈 | 不更换房间；当前人物被聚焦，其他人仍有位置 | 简短对白与三项以内的当前话题；人物立绘如放大仍对应在场者 | 主体是会面而非全屏事务列表 |
| 告辞返回 | 同一镜头、同一对象和业务状态保留 | 对话层关闭，焦点回在场对象 | 不出现只有“重新交谈”的空页面 |

主画面候选选择“与主簿交谈”。环境仍占主体；人物的脸和手不被 UI 挡住。上左只显示“颍川 · 郡府”，上右“中平元年 · 春”；这是虚构样例的游戏标签，不证明具体地方复原。小段对白：“郡中近来多事。足下此来，是为公文，还是打听消息？”话题为“询问差事”“打听近况”“告辞”。

样板中的文字只展示排版意图。真正接入时必须替换为 Godot 的原生文本和输入目标，不能让玩家点击一张整屏烘焙图上的假按钮。

## 实际查阅的参考与推导
1. **已实际查看原图**：[太阁5官方设施内截图](https://www.gamecity.com.tw/manual/taikou5dx/sc/img/3000/3100_02.png)。看到房间占据背景、场所内命令、具象人物和底部对白。取其“房间/人物/命令同处一个情境”，不照搬日式室内、绿色HUD和矩形菜单样式。版权图仅链接研究，不收入产品资产。
2. **已实际查看原图**：[官方据点截图](https://www.gamecity.com.tw/manual/taikou5dx/sc/img/3000/3100_01.png)。看到街道与人物后景、设施卡和分散状态信息。取其场所之间的层级；设施卡式入口不是本样板的强制模式。[官方说明](https://www.gamecity.com.tw/manual/taikou5dx/sc/3100.html)也说明设施内可选人物与话题。
3. **已阅读馆藏文字，未据此声称看过全部文物细节**：[Met 东汉带前院陶望楼](https://www.metmuseum.org/art/collection/search/49520)、[Cleveland 东汉陶望楼](https://www.clevelandart.org/art/1989.71)。用于古代木构空间与人物尺度的历史线索；陶器釉绿不能当成真实房屋原色，也不是官署室内直接证据。
4. **已阅读博物馆文章**：[上海美术馆马王堆生活美学](https://new.artmuseumonline.org/art/art/visitGuide/xwgg/2026/07/04/2c906d9b9e0127fe019f3bdb331225cb.html)。漆木竹器与简帛是材质线索；西汉贵族墓材料不能直接宣称等同汉末郡府陈设。
5. 本轮没有播放连续实机视频，不用静态图推断所有场景转换的时长或动画。后续研究录像必须记录实际观看片段。

## 出图要求
生成单张横向主画面，不是页面拼图/设备模型/海报：精致的二维汉末办事厅堂，光线塑造空间，三个有具体姿态的办事人物；主簿在画面右中部与玩家交流，左方外廊透进自然光；低案、简牍和席垫构成真实工作环境。克制的原生游戏界面视觉位于边缘与下方，仅容纳上文指定的短标签和对白。没有网页导航、卡片网格、开发说明、测试数、LOGO水印、豪华金框。人物和房间优先于菜单。此图用于视觉选择，不伪称运行截图。
